# Spec Delta

## Purpose

为素材提供项目级扁平标签，用于跨目录筛选与组数据集；P0 不要求标签分组。

## ADDED Requirements

### Requirement: 管理扁平标签
系统 SHALL 允许在项目内创建与列出标签，且同一项目内标签名称唯一。

#### Scenario: 创建标签
- **WHEN** 用户在项目中创建标签 `夜班`
- **THEN** 该标签可用于挂到本项目素材上

#### Scenario: 标签重名
- **WHEN** 用户创建与项目中已有名称相同的标签
- **THEN** 系统拒绝该请求

### Requirement: 素材挂载与摘除标签
系统 SHALL 允许给素材挂多个标签、摘除标签，且不得影响素材二进制或所在目录。

#### Scenario: 挂多个标签
- **WHEN** 用户给素材挂上 `夜班` 与 `产线A`
- **THEN** 两个标签均与该素材关联

#### Scenario: 摘除标签
- **WHEN** 用户从素材上移除标签 `夜班`
- **THEN** 该素材不再匹配要求该标签的筛选

### Requirement: 按标签筛选素材
系统 SHALL 支持按标签筛选列出素材（所选标签取交集）。

#### Scenario: 多标签交集筛选
- **WHEN** 用户用标签 `夜班` 与 `产线A` 筛选素材库
- **THEN** 系统仅返回同时具备这两个标签的素材
