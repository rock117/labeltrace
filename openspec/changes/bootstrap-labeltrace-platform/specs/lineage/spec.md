# Spec Delta

## Purpose

提供素材与版本的来源回溯：回答图在哪、贴过什么标签、进过哪些数据集与版本、标注由谁更新，支撑问题样本定位。

## ADDED Requirements

### Requirement: 素材侧回溯
系统 SHALL 能根据素材返回来源类型（如 upload / import）、目录路径（若有）、已挂标签、所属数据集列表，以及包含该素材的已发布版本列表；若来自导入，SHALL 关联到对应导入记录。

#### Scenario: 查看素材血缘
- **WHEN** 用户查询某素材的回溯信息
- **THEN** 响应包含来源类型、目录路径（可空）、标签、引用该素材的数据集，以及包含该素材的版本标识

#### Scenario: 导入素材的来源
- **WHEN** 用户查询由数据集导入产生的素材的回溯信息
- **THEN** 来源类型为 import，并可定位到相关导入记录

#### Scenario: 帧追溯到源视频
- **WHEN** 用户查询 `media_kind=frame` 的素材回溯信息
- **THEN** 响应包含源视频标识以及帧序号（或等价时间位置）

### Requirement: 版本侧清单
系统 SHALL 能根据版本返回快照中的素材清单（含 content hash、划分）及对应标注摘要，用于复现与核对。

#### Scenario: 查看版本组成
- **WHEN** 用户查询某已发布版本的组成
- **THEN** 系统返回该版本冻结的成员与标注相关信息，且与发版快照一致

### Requirement: 标注责任信息
系统 SHALL 在工作标注上保留最近更新者与更新时间，并在素材或数据集上下文中可查询，便于定位「谁标的」。

#### Scenario: 查最近标注人
- **WHEN** 用户查看数据集中某素材的标注元数据
- **THEN** 响应包含最近更新者与更新时间（若存在标注）
