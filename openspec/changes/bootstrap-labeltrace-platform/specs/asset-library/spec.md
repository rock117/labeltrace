# Spec Delta

## Purpose

提供项目级素材库：可嵌套目录、上传到指定目录、移动与列表、内容哈希去重；支持非库可见素材（如导入）；对被数据集或版本引用的素材禁止硬删；二进制经可配置存储后端保存。

## ADDED Requirements

### Requirement: 可嵌套目录树
系统 SHALL 允许在项目内于父目录下创建子目录（可多层嵌套），且同级目录名称唯一。

#### Scenario: 创建嵌套目录
- **WHEN** 用户在父目录 `缺陷样本` 下创建目录 `划痕`
- **THEN** 该目录出现在父目录下，并可通过路径访问

#### Scenario: 同级重名冲突
- **WHEN** 用户创建与已有同级目录同名的目录
- **THEN** 系统拒绝该请求

### Requirement: 重命名目录
系统 SHALL 允许有写权限的成员重命名目录；同级名称仍须唯一；重命名后 MUST 更新该目录及其子孙目录的展示用 `path`。

#### Scenario: 重命名目录
- **WHEN** 用户将目录 `划痕` 重命名为 `划痕-v2`，且同级无冲突
- **THEN** 目录名称与路径更新，其子目录路径前缀同步更新

#### Scenario: 重命名目录同级冲突
- **WHEN** 用户将目录重命名为同级已存在的名称
- **THEN** 系统拒绝该请求

### Requirement: 重命名素材显示名
系统 SHALL 允许有写权限的成员更新库可见素材的显示用 `filename`；MUST NOT 因此改写 `storage_key` 或二进制内容。

#### Scenario: 重命名素材文件名
- **WHEN** 用户将某库可见素材的显示名改为新文件名
- **THEN** 列表与详情展示新名称，对象存储键与文件字节不变

### Requirement: 上传素材到目录
系统 SHALL 接受将图片上传到目标目录，将二进制存于关系库之外的存储后端，并创建关联到该目录的素材记录；经由目录上传的素材 SHALL 默认为素材库可见。

#### Scenario: 上传新图
- **WHEN** 用户将新图片上传到某目录
- **THEN** 系统经当前配置的存储后端写入文件、在该目录下创建库可见素材，并返回素材标识

### Requirement: 可配置的二进制存储后端
系统 SHALL 通过统一存储抽象读写素材（及同类）二进制，不得把本地路径或某一云厂商 API 写死在领域逻辑中。系统 MUST 支持至少两类后端：**本地文件系统**与 **S3 兼容对象存储**；具体启用哪一类（或哪一实例）由部署配置决定。

#### Scenario: 使用本地文件存储
- **WHEN** 部署配置将存储后端设为本地文件系统并上传一张新图
- **THEN** 后续可通过素材内容接口读回与上传一致的字节

#### Scenario: 使用 S3 兼容对象存储
- **WHEN** 部署配置将存储后端设为 S3 兼容服务并上传一张新图
- **THEN** 后续可通过素材内容接口读回与上传一致的字节

#### Scenario: 切换后端实现不影响元数据模型
- **WHEN** 在本地存储与对象存储两种配置下分别完成上传
- **THEN** 素材元数据均包含稳定的存储定位信息（如 backend 标识与 storage key），领域 API 行为一致

### Requirement: 内容哈希去重
系统 SHALL 对上传字节计算内容哈希；当项目内已存在相同哈希时，MUST 复用已有素材，不得再存一份重复二进制。

#### Scenario: 重复内容上传
- **WHEN** 用户上传的图片内容哈希在项目中已存在
- **THEN** 系统不创建第二份对象存储对象，并返回（或提示）已有素材标识

### Requirement: 库可见素材的目录归属
素材库可见（`library_visible = true`）的素材 SHALL 属于且仅属于一个目录；移动仅更新目录归属，不得拷贝二进制。非库可见素材 MAY 无目录归属。目录名与原始文件名 SHALL 支持 Unicode（含中文）及空格；展示用路径 MUST NOT 用作二进制 storage key。

#### Scenario: 移动库可见素材
- **WHEN** 用户将库可见素材移动到同项目下另一目录
- **THEN** 素材仅出现在目标目录下，且其 storage key 不变

#### Scenario: 中文与空格不影响存储键
- **WHEN** 用户在名为 `产线 A` 的目录下上传文件名为 `图 1.jpg` 的图片
- **THEN** 系统保存可读的目录名与文件名供展示，且 storage key 仍基于内容哈希而不包含该中文路径

### Requirement: 通过素材标识读取内容
系统 SHALL 通过素材标识提供内容读取（而非通过用户目录路径拼 URL）；需要下载原始文件名时，SHALL 在响应中以适当方式携带原始 `filename`（支持非 ASCII）。

#### Scenario: 用 assetId 读图
- **WHEN** 客户端请求某素材的内容接口（路径含 assetId）
- **THEN** 系统返回对应二进制，且不依赖 URL 中的中文或空格路径段

### Requirement: 按目录列出库可见素材
系统 SHALL 支持列出某目录下直接包含的、且为素材库可见的素材；默认列表 MUST NOT 包含 `library_visible = false` 的素材。

#### Scenario: 浏览目录内容
- **WHEN** 用户打开某目录
- **THEN** 系统返回该目录下库可见素材列表

#### Scenario: 导入隐藏素材不出现在目录浏览
- **WHEN** 某素材 `library_visible = false` 且 `folder_id` 为空或未挂到用户目录
- **THEN** 普通目录浏览结果中不包含该素材

### Requirement: 引用中的素材禁止硬删
若素材仍被任一数据集成员引用，或仍出现在任一已发布版本快照中，系统 MUST 拒绝硬删除该素材及其对象文件。

#### Scenario: 仍被数据集引用时删除失败
- **WHEN** 用户硬删除仍属于某数据集成员的素材
- **THEN** 系统拒绝删除并保持文件与元数据可用

#### Scenario: 仅被历史版本引用时删除失败
- **WHEN** 素材已不在任何数据集工作区成员中，但仍存在于某已发布版本快照
- **THEN** 系统仍拒绝硬删除该素材
