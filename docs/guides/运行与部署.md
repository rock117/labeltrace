# 运行与部署

面向开发与运维的启动说明。产品操作流程见 [数据集从上传到发版](./数据集从上传到发版.md)；任务队列细节见 [docs/jobs.md](../jobs.md)。

## 架构速览（P0）

| 组件 | 作用 |
|------|------|
| **web** | React 静态资源 + nginx 反代 `/api` |
| **api** | FastAPI；同进程内跑 **PG 任务消费者**（抽帧等，镜像含 ffmpeg） |
| **postgres** | 元数据 + `jobs` 队列（`JOB_BACKEND=pg`） |
| **blob** | 默认 Compose volume `blobs` → `/data/blobs` |

P0 **不**部署独立 worker、**不**使用 Redis。

鉴权：请求头 `X-User-Id`（顶栏可改；默认 `demo-user`）。

## 一键启动（Docker Compose，推荐）

本机只需安装 **Docker Desktop**（含 Compose）。

基础镜像策略：**本地有就用本地**（`pull_policy: missing` / build `pull: false`）；没有则经国内镜像站拉取并打成官方短名。

```bash
# 仓库根目录
# Windows
powershell -File scripts/ensure-base-images.ps1
# Linux / macOS
# bash scripts/ensure-base-images.sh

docker compose up -d --build
```

默认依次尝试（推荐首项 DaoCloud 完整前缀）：
`m.daocloud.io/docker.io/library` → `docker.m.daocloud.io/library` → `dockerproxy.net` / `1ms` / `rat` / `xuanyuan`。可覆盖：

```powershell
$env:DOCKER_MIRRORS = "m.daocloud.io/docker.io/library,dockerproxy.net/library"
powershell -File scripts/ensure-base-images.ps1
```

也可在 Docker Desktop → Docker Engine 配置 `registry-mirrors`（对官方短名 `docker pull` 生效）。构建时 apt / pip / npm 走国内源（阿里云 / 清华 / npmmirror）。
| 服务 | 地址 |
|------|------|
| **Web UI** | http://127.0.0.1:8080 |
| API（调试 /docs） | http://127.0.0.1:8001/docs |
| Postgres | `127.0.0.1:5432`（用户/密码/库：`postgres` / `postgres` / `labeltrace`） |

常用命令：

```bash
docker compose ps
docker compose logs -f api
docker compose down          # 停服务（保留数据卷）
docker compose down -v       # 停服务并删除 pgdata / blobs（慎用）
```

冒烟路径：打开 Web → 创建项目 → 上传视频 → 抽帧审查 → 入集 → 标注 → 发版。

## 环境变量（API）

Compose 已内置默认值；覆盖时可在 `docker-compose.yml` 或 `.env`（Compose 变量）中修改。

| 变量 | 默认 / 说明 |
|------|-------------|
| `DATABASE_URL` | Compose：`postgresql+psycopg2://postgres:postgres@postgres:5432/labeltrace` |
| `BLOB_BACKEND` | `local`（默认）或 `s3` |
| `BLOB_LOCAL_ROOT` | Compose：`/data/blobs` |
| `BLOB_S3_*` | `BLOB_BACKEND=s3` 时使用（可对接 MinIO） |
| `JOB_BACKEND` | P0 固定 `pg` |
| `JOB_POLL_INTERVAL_SEC` | 默认 `0.5` |
| `JOB_LEASE_SEC` | 默认 `300` |
| `LOG_LEVEL` | 如 `INFO` |

切换默认写入后端后，**旧文件仍按 Asset 上记录的 `storage_backend` 读取**。

## 本地热重载开发（可选）

不走镜像、改代码即时生效时使用。依赖：Python 3.11+、Node 20+、ffmpeg、Postgres（可用 `docker compose up -d postgres`）。

### 后端

```bash
cd backend
python -m venv .venv
# Windows
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

### 前端

```bash
cd frontend
npm install
npm run dev
```

开发 UI：`http://127.0.0.1:5173`（Vite 将 `/api` 代理到 `8001`）。

| 镜像 | 内容 |
|------|------|
| `api` | Python 3.12 + ffmpeg；启动时等 PG → `alembic upgrade head` → uvicorn |

## 日后扩展（不阻塞 P0）

- 拆独立 **worker** 容器：仍可 `JOB_BACKEND=pg`，api 只入队；见 `docs/jobs.md`。  
- 队列压力大再考虑 `JOB_BACKEND=redis`（需实现后配置）。  
- 可选增加 MinIO 服务作对象存储。

## 常见问题

| 现象 | 处理 |
|------|------|
| `compose up` 构建失败 | 先跑 `scripts/ensure-base-images.*`；确认 Docker Desktop 在跑；必要时换 `DOCKER_MIRROR` |
| 拉基础镜像超时 | 默认 DaoCloud；也可在 Docker Desktop → Registry mirrors 配国内加速，或改 `DOCKER_MIRROR` |
| Web 能开但接口失败 | `docker compose logs -f api`；确认 api healthy；浏览器访问 `/health` |
| 抽帧失败 | api 镜像已含 ffmpeg；看日志中的 `job_id` |
| 403 权限不足 | 顶栏用户须为项目成员；`viewer` 不能上传；发版仅 **admin** |
| 端口占用 | 改 `docker-compose.yml` 中 `8080`/`8001`/`5432` 映射 |
| 数据要清空重来 | `docker compose down -v`（会删库与 blob） |
