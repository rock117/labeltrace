# 运行与部署

面向开发与运维的启动说明。产品操作流程见 [数据集从上传到发版](./数据集从上传到发版.md)；任务队列细节见 [docs/jobs.md](../jobs.md)。

## 架构速览（P0）

| 组件 | 作用 |
|------|------|
| **web** | React 前端（开发用 Vite；生产为静态资源 + 反代 `/api`） |
| **api** | FastAPI；同进程内跑 **PG 任务消费者**（抽帧等，需 ffmpeg） |
| **postgres** | 元数据 + `jobs` 队列（`JOB_BACKEND=pg`） |
| **blob** | 默认本地目录；可切 S3 / MinIO 兼容 |

P0 **不**部署独立 worker、**不**使用 Redis。

鉴权：请求头 `X-User-Id`（顶栏可改；默认 `demo-user`）。

## 依赖

| 依赖 | 说明 |
|------|------|
| Python 3.11+ | 后端 |
| Node.js 20+ | 前端 |
| PostgreSQL 14+（建议 17） | 本机或 Docker |
| ffmpeg | 抽帧；需在 `PATH` 中可执行 `ffmpeg` / `ffprobe` |

## 本地开发（推荐）

两条终端：API（8001）+ 前端（5173）。Vite 将 `/api` 代理到 `http://127.0.0.1:8001`。

### 1. 数据库

**方式 A：Docker 仅起 Postgres**

```bash
docker compose up -d postgres
```

默认：`postgres` / `postgres`，库名 `labeltrace`，端口 `5432`。

**方式 B：本机已有 PostgreSQL**

创建库后，按下面改 `backend/.env` 的 `DATABASE_URL`。

### 2. 后端

```bash
cd backend
python -m venv .venv

# Windows
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env

# macOS / Linux
# source .venv/bin/activate
# pip install -r requirements.txt
# cp .env.example .env
```

按需编辑 `.env`（至少确认 `DATABASE_URL`）。Compose 默认带密码时示例：

```env
DATABASE_URL=postgresql+psycopg2://postgres:postgres@127.0.0.1:5432/labeltrace
BLOB_BACKEND=local
BLOB_LOCAL_ROOT=./data/blobs
JOB_BACKEND=pg
LOG_LEVEL=INFO
```

迁移并启动（默认 **8001**，避开常见 8000 占用）：

```bash
# Windows
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8001

# macOS / Linux
# alembic upgrade head
# uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

健康检查：`GET http://127.0.0.1:8001/health`  
OpenAPI：`http://127.0.0.1:8001/docs`

启动时会挂载 PG 队列消费者；勿再另起「抽帧 worker」。

### 3. 前端

```bash
cd frontend
npm install
npm run dev
```

浏览器打开：`http://127.0.0.1:5173`

生产构建预览：

```bash
npm run build
npm run preview
```

### 4. 冒烟路径

1. 「项目」创建并选中项目  
2. 「素材库」上传视频 → 抽帧 → 按时间审查删帧  
3. 「数据集」创建 → 加入审查剩余帧 → 「标注台」画框  
4. 「版本」发版

## 环境变量（API）

| 变量 | 默认 / 说明 |
|------|-------------|
| `DATABASE_URL` | SQLAlchemy URL（`postgresql+psycopg2://...`） |
| `BLOB_BACKEND` | `local`（默认）或 `s3` |
| `BLOB_LOCAL_ROOT` | 本地 blob 根目录，如 `./data/blobs` |
| `BLOB_S3_BUCKET` / `BLOB_S3_ENDPOINT` / `BLOB_S3_ACCESS_KEY` / `BLOB_S3_SECRET_KEY` / `BLOB_S3_REGION` | `BLOB_BACKEND=s3` 时使用（可对接 MinIO） |
| `JOB_BACKEND` | P0 固定 `pg` |
| `JOB_POLL_INTERVAL_SEC` | 消费者轮询间隔（默认 `0.5`） |
| `JOB_LEASE_SEC` | 任务租约秒数（默认 `300`） |
| `LOG_LEVEL` | 如 `INFO`；结构化日志含 `request_id` / `job_id` |

切换默认写入后端后，**旧文件仍按 Asset 上记录的 `storage_backend` 读取**。

## Docker 部署

### 当前 Compose

仓库根目录 `docker-compose.yml` **P0 已提供 `postgres` 服务**。`api` / `web` 镜像尚未打进 Compose（本地开发用本机进程即可）。

```bash
docker compose up -d postgres
# 然后按上文启动本机 api + web
```

### 目标形态（规划，与 design D9 一致）

```text
┌─────────────┐     ┌──────────────────────────────┐
│  web        │────▶│  api（单容器）                 │
│  静态 + 反代 │     │  FastAPI + PG 队列消费者       │
└─────────────┘     │  （镜像含 ffmpeg）              │
                    └───────────┬──────────────────┘
                                │
                    ┌───────────┴───────────┐
                    ▼                       ▼
              postgres                 blob volume / MinIO
              （含 jobs 表）
```

落地时建议：

1. **api** 镜像：安装依赖 + ffmpeg；启动命令先 `alembic upgrade head`，再 `uvicorn`（**不要** `--reload`）；挂载或配置 `BLOB_LOCAL_ROOT` / S3。  
2. **web** 镜像：`npm run build` 产物 + nginx（或等价）将 `/api` 反代到 api。  
3. 仅暴露 web（及可选 MinIO 控制台）；postgres 不对外。  
4. 仍保持 `JOB_BACKEND=pg`，抽帧在 api 进程内消费。

示例环境（示意，待镜像就绪后写入 Compose）：

```env
DATABASE_URL=postgresql+psycopg2://postgres:postgres@postgres:5432/labeltrace
BLOB_BACKEND=local
BLOB_LOCAL_ROOT=/data/blobs
JOB_BACKEND=pg
```

### 日后扩展（不阻塞 P0）

- 拆独立 **worker** 容器：仍可 `JOB_BACKEND=pg`，api 只入队；见 `docs/jobs.md`。  
- 队列压力大再考虑 `JOB_BACKEND=redis`（需实现后配置）。

## 常见问题

| 现象 | 处理 |
|------|------|
| 前端接口 404 / 连不上 | 确认 api 在 **8001**；Vite 代理指向 `127.0.0.1:8001`；勿把 `/api` rewrite 掉前缀 |
| 抽帧失败 | 检查 `ffmpeg`/`ffprobe` 是否在 PATH；看 api 日志中的 `job_id` |
| 迁移报错 / 表不存在 | 在 `backend` 下执行 `alembic upgrade head` |
| 403 权限不足 | 顶栏用户须为项目成员；`viewer` 不能上传/抽帧/标注；发版仅 **admin** |
| Postgres 连不上 | `docker compose ps` / 本机服务是否起来；核对 `DATABASE_URL` 用户密码 |
| 8000 端口被占用 | 使用文档中的 **8001**，或改 uvicorn 与 `vite.config.ts` 的 proxy 目标 |
