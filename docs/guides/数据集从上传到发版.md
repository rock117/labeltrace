# 数据集：从上传到发版（操作说明）

面向使用者的短流程说明。系统行为契约以 OpenSpec（`openspec/changes/bootstrap-labeltrace-platform/specs/`）为准；本文不替代验收规格。概念分层与实体关系见 [概念与关系](./概念与关系.md)。

**本项目特点：** 甲方素材以**拍摄视频**为主，很少直接给图片。平台主路径是 **视频 → 抽帧 → 在帧上标注 → 发版导出**。

## 概念（先分清）

| 概念 | 作用 |
|------|------|
| **视频（video）** | 甲方交付的源文件；目录里主要看到它 |
| **帧（frame）** | 从视频抽出的图；入集、画框、进版本/导出的主要单位 |
| 图片（image） | 直接上传的图，或 YOLO 包导入的图；**可与帧混在同一数据集** |
| 素材库 / 目录 | 归档浏览：目录内分「视频 / 上传图片」分页封面；**抽帧图不在目录里平铺**，在所选视频的抽帧任务下审查 |
| 标签 | 项目扁平标签；侧栏「标签」按标签浏览；素材库右键打标签，跨目录筛选 |
| 数据集工作区 | 当前成员（多为 frame）与标注；可一直改 |
| 版本 | 只读快照；训练请用版本导出 |

**规则：** 不在整段视频上画 YOLO 框；已发版本不能改，更新 = 改工作区再发新版。

---

## 主路径：视频 → 抽帧 → 入集 → 标注 → 发版

1. **上传视频**到素材库某目录（上传时服务端截一帧作列表封面；打开目录即可看到画面，不必先点选）。  
2. **抽帧并设置参数**（每隔 N 帧 / 每隔 T 秒）→ 生成**候选帧**（落盘）。  
3. **人工审查**：候选帧按**出现时间顺序**排列（并显示帧号/时间），沿时间线浏览，**批量删掉**模糊、重复、无目标等不需要的帧（通常会删很多）。  
4. **创建数据集**：只填名称。类别在侧栏 **YOLO类别** 创建，会自动进入各数据集。不需要的在数据集页取消勾选（只表示用不用，没有编号）。至少启用一个类别后才能在标注台画框。P0 为检测框。编号在**发版**时才生成。  
5. **加入成员**：多视频时，在**数据集页「从抽帧任务加入」**勾选一个或多个已审查任务，批量把各任务**剩余帧**入集；也可在素材库对当前任务选目标数据集直接入集。上传图仍从库勾选加入。  
6. 数据集详情看**来源摘要**（按视频/抽帧任务分行 + 上传图 / 导入等）。  
7. **标注台**画框后点**下一张**即可（有改动会自动 **提交** 本张；首尾张不可再翻）；也可用「提交全部草稿」一次收口。中途停手用「仅存草稿」。  
   - **未标注** = 还没处理过，不能当负样本。  
   - **提交且无框** = 确认本图无目标（null / 负样本），算已提交，可以发版。  
   发版要求每名成员均为已提交。工作区不展示「未分配」等划分标签。

  
8. **发版**（全部成员都已提交后才能发）：在发版时填写 **train/val/test 比例**（可随机种子），系统按比例随机划分并冻进版本快照。  
9. **导出 YOLO**：在「版本」页对该版本点 **导出 YOLO**，后台打 zip（`train|val|test` 的 images/labels + `data.yaml`）；完成后自动下载。包内文件名按规则重生（避免重名/中文）；无框图仍有空 label（负样本）。  
10. 已发版本可 **查看快照**（只读）；工作区标注台仍是实时可编辑数据。  
11. 在快照或版本列表可 **应用到工作区**：把该版本成员与标注**合并**进当前工作区（同图覆盖标注并变为草稿；快照有而工作区没有的图会入集；工作区多出的图保留）。  
12. 数据集可将成员 **移出**（只删引用，不删素材库文件）。

图片也请先在**素材库**上传，再到数据集页从库勾选加入（数据集页不提供本地上传）。可与抽帧 frame 混在同一集。  


**注意：** 抽帧 ≠ 自动入集；审查剔除发生在入集之前（已入集的帧要先移出集才能硬删）。

---

## 辅路径：已有 YOLO 图片包

在**数据集**页上传 **YOLO detect zip**（须含 `data.yaml` 与 `train|val|test/images` + 对应 `labels`；与平台导出格式一致）→ 新建数据集（或导入到**空**数据集）→ 图成员 `origin=import`、**不进素材库目录** → 标注已按标签写入（submitted）→ 可直接发版。内容哈希去重：已有图只加引用不重复存盘。仅项目负责人可导入。

## 数据来源在数据集里怎么记

| 层级 | 记什么 |
|------|--------|
| 每一张成员 | Asset 上的 `media_kind`、`origin`；帧另有**源视频**、**原视频第几帧（frame_index）**、抽帧任务；上传图有目录/文件名；导入有 `import_id` |
| 数据集详情 | 聚合摘要 `memberSources`（抽帧 / 上传 / 导入各多少、抽帧参数等） |
| 已发版本 | 快照里带上来源摘要，可复现当时构成 |

---

## 更新已有数据集（又拍了新视频）

1. 上传新视频 → 抽帧。  
2. 打开原数据集 → 把新视频的帧**追加**进去。  
3. 只标新帧（或未标帧）。  
4. 发布 **新版本**（如 v1.1）；旧版本不变。

## 常见问题

**问：为什么不能直接在视频时间轴上标？**  
P0 先抽成帧再标，好接 YOLO 与版本；完整时间轴 UI 后续再做。

**问：帧会不会把素材库撑爆？**  
目录浏览以视频为主；帧挂在视频下，避免海量缩略图刷屏。

**问：训练导出的是视频还是图？**  
导出的是**帧图 + 标签**（YOLO detect）；血缘里仍能追回源视频。
