# 与主流标注平台的差异与待补功能

对照 Roboflow / CVAT / Label Studio / FiftyOne 等常见平台，梳理 LabelTrace **已有优势**、**相对偏弱处**，以及**后续可能需要的功能**。

行为契约仍以 OpenSpec（`openspec/changes/bootstrap-labeltrace-platform/specs/`）为准；下文「可能需要」**尚未全部写入 tasks**，落地前需另开或扩展 change。

---

## 1. 相对较强（已有或已规划）

| 能力 | 说明 |
|------|------|
| 视频→抽帧→审查→入集 | 规格完整，偏视频交付场景 |
| 素材库 + 内容哈希去重 + 引用不拷贝 | 多数据集可共享同一素材 |
| 不可变版本 + 父版变更摘要 + 发版门槛 | 含未标注 / 负样本（无目标）区分 |
| 工作区可编辑 vs 版本只读 + 合并回工作区 | 版本浏览不污染工作区 |
| 帧→源视频血缘 | 可回答「训练图对应原片哪一帧」 |
| YOLO 导入 / 按版导出 | 接训练与存量 YOLO 包 |
| 项目成员与角色 | 有鉴权边界（能力偏薄） |

---

## 2. 相对主流明显偏弱

### 2.1 导入 / 导出格式面窄

| 主流 | LabelTrace（当前） |
|------|-------------------|
| COCO / VOC / YOLO 等多格式进出 | P0 **仅 YOLO** detect |

旧项目、外包包若不是 YOLO，接入成本高。

### 2.2 质检 / 审核流

| 主流 | LabelTrace（当前） |
|------|-------------------|
| review、通过/驳回、驳回原因 | 仅 `draft` / `submitted` |
| 问题图标记、返工队列、图上评论 | **无** |

`submitted` 不等于质检通过；多人协作时数据质量难控。

### 2.3 任务分配

| 主流 | LabelTrace（当前） |
|------|-------------------|
| 按人分图、任务包、完成率 | 仅项目级角色 |
| 占用/锁定，防多人抢同一张 | **未规定** |

### 2.4 数据集健康度

| 主流 | LabelTrace（当前） |
|------|-------------------|
| 类别分布、空标/负样本占比、难例视图 | 标注台有进度计数 |
| 按类、有无框、来源等运营筛选 | 胶片可按状态筛；集/库侧运营视图弱 |

发版前缺少「这批数据是否均衡、缺口在哪」的一眼结论。

### 2.5 标注与版本变更可下钻

| 主流 | LabelTrace（当前） |
|------|-------------------|
| 单图标注修订历史 | 仅最近 `updated_by` / `updated_at` |
| 版本间逐图/逐框 diff | 仅有**计数级**变更摘要 |

排错「谁改坏了 / 两版差在哪」能力不足。

### 2.6 机器集成

| 主流 | LabelTrace（当前） |
|------|-------------------|
| API Key、Webhook（导入/导出/发版完成） | 人账号 JWT |
| 对内稳定 API 契约说明 | 有 HTTP 设计，未单列成平台集成文档 |

训练流水线、脚本接入不如「开箱可当服务用」顺手。

---

## 3. 主流有、可明确后置

| 能力 | 说明 |
|------|------|
| 多边形 / mask / pose / OBB 等 | 架构已预留；按业务需要再实现 |
| 视频时间轴 + 跨帧 track | P0 用抽帧替代，合理后置 |
| 模型辅助预标 / 主动学习 | 非数据管理第一优先级 |
| 标签分组 / 类别本体层级 | 复杂产线再要 |
| 组织树 / SSO | 公司 IT 要求时再上 |
| 在线训练托管 | 已非目标 |

---

## 4. 可能需要有的功能（建议优先级）

按「补齐协作与数据运营」优先，而不是先对齐竞品功能清单：

1. **更宽导入** — 按团队存量最大的 1～2 种格式（如 COCO）排队  
2. **审核流** — 例如 submitted → reviewed，支持驳回与原因  
3. **任务分配** — 将数据集成员子集分给标注员；可选占用/锁定  
4. **API Key + 任务完成回调** — 发版/导出完成后通知下游  
5. **数据集健康度** — 类别分布、未标注/负样本占比、按条件筛选成员  
6. **标注/版本可下钻历史** — 单图修订记录；版本间成员与标注 diff  

几何类型（polygon 等）、时间轴 track、预标等：有明确业务需求再排期。
